# Mitmachen

Danke, dass du den Ansible-Kurs besser machen willst.

## Fehler melden

Eine Aufgabe ist unklar, eine Musterlösung falsch oder der Prüfer meldet
etwas, das nicht stimmt? Dann bitte ein
[Issue](https://github.com/Dschonas04/Ansible-Kurs/issues/new/choose) mit:

- Level und Aufgabe, um die es geht,
- was du erwartet hast und was passiert ist,
- Betriebssystem und Version des Werkzeugs.

## Änderungen vorschlagen

1. Repository forken und einen Zweig anlegen.
2. Änderung machen. Jede Aufgabe besteht aus Aufgabenstellung, Übungsdatei,
   Musterlösung in `Loesungen/` und einer Prüfung.
3. Lokal prüfen, die Musterlösungen müssen grün sein:

   ```bash
   ./pruefen.sh --loesung
   ```

4. Pull Request öffnen und kurz beschreiben, was sich ändert und warum.

## Stil

- Deutsch mit echten Umlauten (ä, ö, ü, ß).
- Aufgaben beschreiben das Ziel, nicht den Lösungsweg.
- Jede neue Aufgabe bekommt eine Prüfung, sonst kann niemand sicher sagen,
  ob sie gelöst ist.
